Job Hunt Guide
🎯

This section activates from Month 7 onwards. But start building your profile, GitHub, and LinkedIn from Day 1. Recruiters look at your commit history — green squares matter.

📄 Resume Building

  • ATS-friendly: single column, no tables, no graphics
  • Tools: Resumake.io, FlowCV.io, Canva (simple)
  • Order: Skills → Projects (2–3) → Experience → Education
  • Projects > Everything. GitHub URL + live demo on each
  • Skills: React, Node.js, Express, MongoDB, PostgreSQL, TypeScript, Git
  • 1 page only. No objective statement. Start with a summary line
  • Quantify: "Built REST API handling 500+ req/sec" not "Built an API"

🌐 Online Presence

  • GitHub: Pin 3–4 best projects. README with screenshots + demo link
  • LinkedIn: 500+ connections. Post your projects with write-ups
  • Portfolio: Simple Next.js or HTML. 3 projects, live demo + code
  • Twitter/X: Tweet your learning — devs hire devs they know
  • Contribute to open-source. Even fixing a typo counts
  • Write 2–3 blogs on Hashnode/Dev.to

🏢 Job Sites — India

  • Naukri.com — largest Indian job board. Fill 100% profile
  • LinkedIn Jobs — set job alerts for "React Developer"
  • Instahyre.com — startups match you to jobs
  • Cutshort.io — startup-focused, great for freshers
  • AngelList / Wellfound — startups directly
  • Internshala — first internship → then full-time
  • YC Work at a Startup — YC-backed companies

🌍 Remote Jobs

  • Remote.co — curated remote dev roles
  • We Work Remotely — top remote board for devs
  • Remotive.io — remote tech, India-friendly
  • Toptal — hard screening, huge pay
  • Turing.com — vetted roles for Indian devs
  • Deel companies — hiring via Deel from India
  • X/Twitter DMs — US startup CTOs hire via DMs

Resume Tips
Project descriptions that get interviews:
❌ "Built a to-do app using React"
✅ "Built a full-stack task manager with React + Node.js + MongoDB. Features: JWT auth, real-time updates with Socket.io, deployed on Vercel + Railway. 200+ GitHub stars."
Cold outreach template (LinkedIn):
"Hi [Name], I noticed [Company] is building [Product]. I'm a self-taught full-stack developer with projects in React/Node. I shipped [X project] recently — [GitHub link]. Would love to explore if there's a fit. No pressure if not the right time."

Your data is stored only in this browser. Clearing browser data or switching devices will erase everything. Export a backup weekly and save to Google Drive.
