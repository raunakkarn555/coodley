Job Hunt — Complete Guide to Getting Hired

This is your battle plan. Follow these phases in order. Each step is designed to maximize your chances of landing a ₹15 LPA+ offer. Start Phase 1 from Day 1 of your journey — don't wait for Month 7 to start building your profile.

01

Foundation Building — Start from Day 1

Before you write a single line of JS, your online presence should begin. Recruiters look at dates — an account created 6 months ago looks more credible than one made last week.

Month 1–3
Create & optimize your GitHub profile
Set a professional photo, bio with "Full Stack Developer | React • Node.js", and location. Pin 3–4 repos. Add a README to each repo with screenshots, tech stack, and a live demo link. Enable GitHub profile README (create repo named same as your username).
github.com ↗ README Examples ↗
Build a strong LinkedIn profile (500+ connections)
Photo (professional, good lighting), headline: "Full Stack Web Developer | React • Node.js • Building in Public". Fill ALL sections. Connect with 10+ devs per day (search "software developer", "SDE", "React developer"). Post about your projects with screenshots — LinkedIn gives massive reach to builders. Turn on "Open to Work".
LinkedIn ↗ React Jobs ↗
Commit to GitHub every single day
Even 1 commit per day keeps your profile green. Recruiters look at contribution graphs. Build your projects publicly from day 1. "Building in public" is a massive credibility signal. Create a "100DaysOfCode" repo and push daily logs.
100DaysOfCode ↗
02

Project Portfolio — Build Things That Get You Hired

Your projects ARE your resume. 2 strong projects with live demos beat 10 half-finished ones. Each project should show: problem-solving, full-stack thinking, clean code, and real deployment.

Month 4–6
Project #1 — Full-Stack CRUD App (Authentication)
Build a full-stack app with: JWT auth, protected routes, CRUD operations, MongoDB or PostgreSQL, deployed on Vercel + Railway. Example: Blog platform, Notes app, Task manager. Must have: Live demo link, GitHub with good README, screenshots.
Deploy on Vercel ↗ Backend on Railway ↗
Project #2 — Real-time or Advanced Feature App
Something that shows advanced skills: Real-time chat (Socket.io), SaaS dashboard with charts, E-commerce with payment integration (Razorpay), or a developer tool. This project should make interviewers say "Oh, interesting."
Socket.io Docs ↗ Razorpay API ↗
Build a Portfolio Website
Simple, fast, impressive. Use: Next.js or plain HTML. Must have: Hero with your name + title, Projects section (3 with screenshots + live + GitHub), Skills, About, Contact (email form). Sub-3 second load time. Mobile responsive. Custom domain optional (use .vercel.app or Netlify subdomain).
Great Example ↗ Portfolio Ideas ↗
Write 2–3 Technical Blog Posts
Write about things you built or learned. "How I built X with React and Node.js". "5 things I wish I knew about async/await". This builds credibility, improves communication, and shows up in Google. Hashnode and Dev.to give you free domain and SEO.
Hashnode ↗ Dev.to ↗
03

Active Job Application — Cast a Wide Net

Apply to 5–10 companies per week. Not 2. Not 50. 5–10 gives you focus with breadth. Track everything. Follow up after 1 week. The job market is a numbers game — more applications = more chances.

Month 7–8
India Job Boards — Apply in this order
Cutshort and Instahyre are startup-focused with less competition. Naukri has volume. LinkedIn is relationship-first. AngelList/Wellfound is for early-stage startups (often best pay). Fill your profile to 100% on each platform before applying.
Cutshort ↗ Instahyre ↗ Naukri ↗ AngelList ↗ Internshala ↗
Referral Network — The #1 way to get interviews
80% of jobs are filled through referrals. DM people on LinkedIn who work at companies you want to join. Message format: "Hi [Name], I noticed [Company] is building [X]. I'm a self-taught full-stack developer. I shipped [project link] recently. Would you be open to a referral or 10-min call?" Be specific. Be brief. Have something to show.
Find Engineers ↗
Remote / International Jobs
Remote jobs from US/EU companies often pay 3–5x Indian market rates via Deel/Wise. Target: YC startups, Series A companies with remote policies. Look at company Careers pages directly — not just job boards.
YC Jobs ↗ Remotive ↗ We Work Remotely ↗ Turing ↗
Twitter/X — Cold DM to CTOs and Founders
Many indie hackers and small startup CTOs hire via Twitter DMs. Follow devs at companies you admire. Engage with their posts genuinely for 1–2 weeks. Then DM with your portfolio. "I've been following your work on [X]. I'm a full-stack developer looking for my first role. Here's what I've built: [link]. Would love to contribute."
Search Hiring Tweets ↗
04

Interview Phase — Convert Calls to Offers

Getting the interview is 50% of the battle. The other 50% is preparation. Most developers fail interviews not because they're bad coders — but because they haven't practiced articulating their thinking.

Month 7–9
Do 5+ mock interviews before your first real one
Pramp.com pairs you with another developer for free 1:1 mock interviews. Interviewing.io is anonymous with senior engineers. Ask friends or classmates to interview you. Record yourself answering questions and watch it back — painful but revealing.
Pramp — Free Mocks ↗ Interviewing.io ↗ Exponent ↗
Live Coding — Think out loud, always
Never code silently. Say what you're thinking: "I'll start with a brute force O(n²) approach, then optimize." Confirm the question. Give examples. Talk through edge cases. Write clean variable names. "I'm using a hash map here because lookup is O(1)." Interviewers want to see how you think.
LeetCode ↗ NeetCode 150 ↗
Company Research (must do before EVERY interview)
1) Use their product for 30 minutes. 2) Read their engineering blog. 3) Check their GitHub for tech stack. 4) Look at LinkedIn to see team size and recent growth. 5) Glassdoor for interview questions. This shows genuine interest and sets you apart from 90% of candidates who don't bother.
Glassdoor India ↗
05

Offer & Negotiation — Don't Leave Money on the Table

The average first offer is 15–20% below what you can actually get. Negotiating is expected. Companies budget for it. If you don't negotiate, you're literally leaving money on the table.

Month 8–9
Research market rates BEFORE any salary discussion
Know the numbers. Freshers with strong projects: ₹8–18 LPA depending on company. Know your anchor number before any call. When asked, say "Based on my research, I'm targeting ₹[X]–[Y] LPA." Don't say a specific number first if possible.
Levels.fyi ↗ Glassdoor Salaries ↗ AmbitionBox ↗
Always have competing offers or create urgency
Apply to multiple companies simultaneously (not sequentially). When you get an offer, tell other companies: "I have an offer with a deadline of X. I'd love to work with you — is there any way to expedite?" This creates leverage. Even a potential offer matters. Never lie, but always communicate timelines honestly.
Before You Apply — Complete This Checklist

Resume Rules — Non-Negotiable

  • 1 page only. Recruiters spend 7 seconds on a resume. Make it scannable.
  • ATS-friendly: plain text, no tables, no text boxes, no columns — use single column
  • Order: Summary → Skills → Projects (2–3) → Experience → Education
  • Projects come BEFORE experience for freshers. Your code is your experience.
  • Every project: tech stack, GitHub link, live demo, 2–3 impact bullets
  • Skills section: React, Node.js, Express, MongoDB, PostgreSQL, TypeScript, Git, REST APIs
  • No objective statement. Use a 2-line summary instead.
  • Quantify EVERYTHING: "500+ users" not "many users". "30% faster" not "improved performance"

Project Bullet Formula

❌ Bad: "Built a to-do app using React"

✅ Good: "Engineered a full-stack task manager with React + Node.js + MongoDB — featuring JWT auth, real-time sync via Socket.io, drag-to-reorder (React DnD), deployed on Vercel + Railway with CI/CD via GitHub Actions"

Resumake.io — Free Builder ↗ FlowCV.io ↗ Canva Templates ↗ JSON Resume ↗

Cold Outreach Template (LinkedIn DM)

"Hi [Name], I noticed [Company] is building [specific product/feature]. I'm a self-taught full-stack developer with React/Node. I shipped [project name] recently — [link]. Would love to explore if there's a fit. No pressure if not the right time."

JavaScript Must-Know

  • Closures — write an example using a counter function
  • Event loop — microtasks vs tasks, why setTimeout runs last
  • Promises vs async/await — when to use Promise.all
  • this keyword — 4 binding rules, arrow function difference
  • Prototype chain — how inheritance works in JS
  • Hoisting — var vs let vs const behavior
  • == vs === — type coercion rules

React Must-Know

  • Virtual DOM — how reconciliation works
  • Hooks rules — why can't you call hooks conditionally
  • useEffect — cleanup, deps array, infinite loop gotcha
  • React.memo, useMemo, useCallback — when to use each
  • Why keys matter in lists — reconciliation algorithm
  • Controlled vs uncontrolled components
  • Lifting state up — the correct mental model

System Design Must-Know

  • "Design a URL shortener" — walk through step by step
  • Horizontal vs vertical scaling — trade-offs
  • When to use SQL vs NoSQL — give examples
  • What is a CDN — how does it improve performance
  • REST vs GraphQL — when to use each
  • How does JWT auth work — security trade-offs
  • What happens when you type a URL — full breakdown

Behavioral Questions — STAR Method

Situation, Task, Action, Result. Prepare 3–4 stories for: "Tell me about a project you're proud of", "Describe a challenge you faced", "How do you handle not knowing something". Keep each answer to 2–3 minutes.

Negotiation Script

When they give an offer: "Thank you so much — I'm really excited about this role. I was hoping we could get to [X+20%] based on my research on [Glassdoor/AmbitionBox] and the projects I've shipped. Is there flexibility there?" — then STAY SILENT. The first one to speak loses.

Beyond Base Salary — Negotiate These Too

  • ESOPs — equity in early-stage startups can be worth more than salary
  • Joining bonus — often easier to get than salary increase
  • Learning budget — ₹50K–1L/year for courses, conferences
  • WFH days — 3 days WFH = ~₹5,000/month saved in commute
  • Start date — negotiate a later start date if you need a break
